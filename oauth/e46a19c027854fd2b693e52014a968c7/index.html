zops-email-link

zops-email-link is a personal email integration operated by Kamran Hakiman for his own Google accounts. It supports Gmail access through his configured assistant integrations and automated maintenance and backup notification emails.

Gmail access through the assistant integration is configured for read-only tools. The separate notification sender uses deterministic software and Gmail SMTP to send automated notices; sending a standard notice does not require an AI agent.

This application is intended for the owner's personal use. It does not offer public registration.

Google's SMTP authorization requires a broad mail permission. That permission can technically allow reading, sending, and deleting mail. The notification sender's implemented function is to send configured notices; the assistant integration's tool permissions remain read-only.

Questions about this application or its handling of Google account data can be sent to zops.kamran@gmail.com.
